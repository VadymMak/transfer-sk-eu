# Transfer GmbH Demo

Airport transfer service — Vienna ⇄ Bratislava.

Built on **vendshop-template-services** (Next.js 15, Prisma v7, Neon PostgreSQL, Vercel Blob).

## Stack
- Next.js 15 App Router + next-intl (de/sk/cs/en)
- Prisma v7 + Neon PostgreSQL
- Vercel Blob (image uploads)
- Admin panel at `/admin`
